# 🇲🇽 México Participa: Seis Historias

**Análisis interactivo de la participación ciudadana basado en los Conteos Censales (CCPC) 2009–2024.**

Este proyecto fue desarrollado para el Hackathon INE 2026, enfocado en el **Reto 3: Storytelling con datos**. El objetivo es transformar los datasets técnicos del INE en una narrativa editorial comprensible y accionable para la ciudadanía.

## 🚀 Características Principales
- **Narrativa en Actos:** El sitio guía al usuario desde la tendencia nacional hasta el análisis regional.
- **Análisis Territorial:** Selector de estados para comparar la realidad local frente al promedio nacional.
- **Datos Verificados:** Procesamiento de datos crudos del INE mediante Python y Pandas.
- **Visualizaciones de Alto Impacto:** Implementación de Apache ECharts para series temporales y análisis de brechas.

## 🛠️ Stack Tecnológico
- **Frontend:** React, TypeScript, Vite, Tailwind CSS.
- **Visualización:** Apache ECharts.
- **Análisis de Datos:** Python, Pandas.
- **Despliegue:** Vercel / GitHub Pages.

## 📂 Estructura del Proyecto
- \/app\: Código fuente del prototipo web.
- \/data\: Datasets crudos y procesados.
- \/analysis\: Scripts de limpieza y extracción de hallazgos.
- \/docs\: Guion narrativo y documentación técnica.

## 📈 Hallazgos Clave
- **Brecha Electoral:** Se identificó una diferencia significativa de participación entre estados, evidenciando una fragmentación territorial en la cultura del voto.
- **Volatilidad Temporal:** La participación ciudadana muestra ciclos de oscilación marcados entre las elecciones federales y presidenciales.
